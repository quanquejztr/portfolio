# Technology logos

Existing technology logos and nextjs.svg, fastapi.svg, duckdb.svg, postgresql.svg: Devicon (MIT; see DEVICON-LICENSE.txt), https://github.com/devicons/devicon. Original SVG artwork retained.

langchain.svg and apacheparquet.svg: Simple Icons (CC0), https://github.com/simple-icons/simple-icons, https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md. Monochrome artwork is displayed in white against the navy page.

zstandard.png: official Zstandard project artwork, https://github.com/facebook/zstd/blob/dev/doc/images/zstd_logo86.png. Used to identify the compression technology.

Names and logos belong to their respective owners. These assets identify technologies used in the described project.

Apple stack: apacheairflow.svg and bitbucket.svg are from Devicon (MIT). fastmcp.svg is the official FastMCP favicon from https://github.com/PrefectHQ/fastmcp/tree/main/docs/assets/brand. pydantic-ai.svg is official Pydantic AI white logo artwork from https://github.com/pydantic/pydantic-ai/blob/main/docs/img/logo-white.svg. Existing Python and Kubernetes assets are reused. Java WatchService uses the Java logo; Bitbucket API uses the Bitbucket logo.
